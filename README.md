# 出張の持ち物

日別の「仕事・移動・私用」、日数、行き先に合わせて持ち物を確認する、日本語・モバイル対応の個人用ツールです。

## できること

- 出張タイトルと各持ち物のメモ（標準・独自追加品ともに対応、自動保存）
- 仕事・電源に顧客用資料、研修・会議用資料、筆記用具、even G2 R1を追加

- 1〜30日の日程と、各日の目的を複数選択
- パンツ・靴下・肌着などの数量計算。出発日に着る1日分を除き、洗濯なしで計算
- 仕事の目的に応じたPC・電源・ヘッドセット・資料など、アメニティのチェック
- 新幹線・飛行機・高速バス等の予約／購入確認と、当日使う券・QRの準備を別々にチェック
- 行き先の都市候補を選び、現地日付別の天気・最高／最低気温・降水確率を表示
- 数量の上書き、不要からの復帰、持ち物の追加、未チェック絞り込み、確認付きチェックリセット

## データとプライバシー

タイトル・メモ・予定・数量・チェックは、このサイトを開いている端末・ブラウザーの localStorage に保存します。GitHubやアプリのサーバーへは送信しません。別の端末・ブラウザーには同期されず、サイトデータを削除すると保存内容も消えます。同じブラウザープロファイルを使う人は保存内容を閲覧できます。

天気検索時だけ、入力した都市名を Open-Meteo の地名検索へ、選んだ都市の緯度・経度を天気APIへ送信します。位置情報の自動取得や個人アカウントの連携は行いません。天気が取得できない場合でも持ち物チェックは使えます。初回ページ読み込みには通信が必要です。

## 計算の前提

各日の目的は重複できます。仕事＋私用の日はそれぞれの服装を用意しますが、下着は1日分です。移動のみの日は私服として扱います。上下・靴・部屋着は着回す目安であり、必要に応じて数量を変更してください。数量が増えたチェック済み品目は再確認が必要になります。

チケットのチェックは本人が確認するための項目です。予約・購入・支払い・チェックインそのものを行う機能はありません。

## 天気

[Open-Meteo](https://open-meteo.com/) の個人・非商用向け無料APIを使用します。今日を含む最大16日分の予報から出張日付に一致するものだけを表示し、過去や範囲外の日付は予報なしと表示します。日付は各行き先の現地日付です。

天気データ: [Open-Meteo](https://open-meteo.com/) / [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)（天気コードの表記を日本語に変換）
地名データ: [GeoNames](https://www.geonames.org/)
商用利用・大規模な利用へ転用する場合は [利用条件](https://open-meteo.com/en/terms) とAPIの制限を確認してください。

## 開発

Node.js 22.13以降（推奨24）。

```sh
npm install
npm test
npm run dev
npm run build
```

`npm run build` が `docs/` に静的サイトを生成します。GitHub Actionsが main ブランチのソースからビルドし、GitHub Pagesへ公開します。別のリポジトリ名へ移す場合は `vite.config.ts` の `base` を変更してください。

UIはReact、Vite、Tailwind CSS、Radix UIを使用します。ベンダーCSSのライセンスは `vendor/` に収録しています。
